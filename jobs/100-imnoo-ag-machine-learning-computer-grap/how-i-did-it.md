# How this package was generated

- Source listing captured by `scripts/discover_jobs.py` from Arbeitnow.
- Fit score, keywords, headline, and summary written by local Ollama model `phi3:mini`.
- Resume built from `templates/resume-template.tex` with a role-specific headline and summary — score below threshold, so the base resume was used.
- Cover letter paragraphs generated by `phi3:mini` and inserted into `templates/cover-letter-template.tex`, compiled with pdflatex.
- Score: 30/100 (skip). Reasons: Automated LLM analysis unavailable; heuristic score from title keywords. Review manually.; Seniority flag: role targets senior/staff-level candidates; early-career candidate.
